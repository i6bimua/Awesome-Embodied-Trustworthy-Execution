# Figure Notes

Each image is a representative figure used to help readers quickly understand the corresponding paper.

- Paper IDs match the `PXX` numbering in the root `README.md`.
- Figures are cropped excerpts from the original papers or the source survey used to build this list.
- Copyright remains with the original authors/publishers.
- For reuse beyond scholarly review/navigation, follow the license and attribution requirements of the original paper.

For papers P02, P03, P06, P20, P23, and P26, the figures were re-extracted from the original PDFs supplied by the repository maintainer, replacing the earlier placeholder concept cards.
